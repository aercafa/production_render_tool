模型出图工作台｜网页版便携版 v0.3.3

1. 将 ZIP 完整解压到一个文件夹。
2. Windows 双击 Start-Workbench.cmd。Mac 双击 Start-Workbench.command。
3. 工作台会在默认浏览器打开。推荐使用 Chrome 或 Edge。
   如浏览器没有打开，请复制启动窗口显示的 http://127.0.0.1 地址。
4. 使用期间保留启动窗口。用完后按 Ctrl+C 或关闭窗口即可停止服务。

更新前先关闭旧版启动窗口，更新原目录中的程序文件后启动。界面左上角显示版本号。
新导入会用模型文件名（去掉 .3dm / .obj）自动填写图片底部的辅助说明，仍可编辑。
材质统一按整组编辑；图上点选部件后，共用该材质的所有部件一起更新。
同名且参数与贴图一致的 Rhino 重复材质定义自动合并；不同表面保留独立。
AI 响应有格式或目标错误时自动修正一次，仍失败会明确提示，不会静默忽略。
导出文件名优先使用最后编辑的题目；题目为空时使用最后的辅助说明。
例如：题目 L29 → L29.png；没有题目、辅助说明 L29终端 → L29终端.png。
本版改进高保真布光与材质，在右栏新增光箱 Z／Y 轴角度滑块（−180°～180°）。
左侧上方为渲染历史，下方为较短的对话助手。每次成功导入仅生成一条记录，
后续材质、灯光、视角和标注调整更新该条最后效果。重复导入才新增记录。
历史包含缩略图、导入时间和来源位置。Windows 原生选择器记录完整路径；
点击记录可重新载入源文件和最后效果。浏览器／拖拽来源不提供完整路径时，
界面会明确标注；刷新后按提示重新选择源文件。取消或失败不新增记录。
历史仅保存在当前浏览器与工作台地址，最多 18 次；不复制整份模型或 API Key。

便携包含 Node.js 运行环境及预编译网页，解压后可离线启动。
Windows 包适用于 x64；Mac 请按「关于本机」选择 Apple 芯片或 Intel 包。
若 macOS 拦截下载脚本，请在确认来源后按系统提示允许打开。

可直接导入 OBJ 和带显示网格的 3DM。Windows 如需自动转换缺网格的 3DM，
请先在同一台电脑安装并激活 Rhino 8。Mac 可先在 Rhino 另存带网格的副本。
使用渲染助手时，在工作台设置中填写兼容的 API 地址、模型名和 Key。
