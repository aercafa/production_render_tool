# 模型出图工作台｜项目复盘与开发经验

这款工具把产品或展项的 3D 模型转成一张可直接用于方案沟通的图。左侧是轴测，右侧是同尺度三视图。使用者可核对外廓、填写名义尺寸、加局部标注、调整材质，最后导出高清 PNG。复盘以本仓库的网页版实现为准，后续迭代指标均为建议值。

## 产品范围与技术选型

工作台把导入、标注、材质和出图放在单页。预览跟随可用空间缩放，编辑栏独立滚动，导出入口常驻右栏底部。沿用浏览器作为试用入口，可以快速验证图纸和材质交互，核心流程也能复用到桌面壳。

| 层 | 技术 | 负责什么 |
| --- | --- | --- |
| 工作台 | TypeScript、Vite、Canvas 2D | 界面、画布布局、尺寸和文字、预览与 PNG 合成 |
| 3D | Three.js 0.187、WebGL2 | 正交投影、材质与光照、环境反射、接触 AO、线描与辉光 |
| 读模 | OBJ/MTL Loader、rhino3dm 8.35 WASM | 读取网格、材质与单位，检查 3DM 是否含可用显示网格 |
| 本机服务 | Node.js、Windows Rhino 8 批处理 | 曲面转网格、进度和缓存、目录设置、保存图片、转发模型 API |
| 验证 | Playwright、Chrome | 测试用户操作、输出尺寸、渲染像素、缓存与模拟 API |

## 各功能如何实现

| 功能 | 实现 | 关键参数与代码入口 |
| --- | --- | --- |
| 模型导入 | 一次导入一个 OBJ 或 3DM，可附带 MTL 和贴图。OBJ 的引用按文件名匹配。3DM 在 Web Worker 中检查显示网格，保留源材质身份、可见性和原单位。导入失败时保留上一张画面，并提示重试。 | OBJ 支持 mm、cm、m、in、ft，默认未知；3DM 检查超时 45 秒。[导入逻辑](../src/model.ts) · [3DM 检查](../src/rhino-check.worker.ts) |
| 自动网格 | 缺显示网格时调用本机 Rhino 8。转换展开可见块实例，保留对象或图层材质、显示色和单位，生成独立网格副本，前端再次检查。并发时按顺序处理，进度区显示排队、转换和写缓存。 | 容差 0.025 mm、最短边 0.08 mm（按模型单位换算）、网格与细化角 6°，启用平面简化和网格细化。最多 1 个执行、3 个等待，Rhino 超时 240 秒，源文件和输出上限 256 MiB。[转换脚本](../server/rhino-mesh.py) · [本机服务](../server/local-workbench.mjs) |
| 居中和四视图 | 用可见网格的世界坐标包围盒求尺寸。仅在渲染场景内居中并按最长轴归一化。左侧轴测独立适配，右侧俯视、正视、右视共享比例。切换镜头只改左图，当前材质和编辑历史继续有效。 | 逻辑图幅 1200 × 800，坐标 X 向右、Y 向后、Z 向上。六档轴测涵盖前左、前右、后左、后右和底部前左、前右。默认前右方位约 34.82°，仰角约 22.26°。[版式和相机](../src/sheet.ts) |
| 外廓与文字 | 总宽、总深、总高来自导入网格范围。用户填写名义值后覆盖图面文字，几何和视图比例沿用实际范围。可恢复实测、编辑题目与说明。 | 毫米显示最多两位小数。题目最多 70 字、说明最多 180 字、单个外廓标注最多 30 字。[输入与状态](../src/main.ts) · [绘制规则](../src/sheet.ts) |
| 局部尺寸 | 指针坐标映射到逻辑画布。正交自动按拖动主方向吸附，也支持自由拉线；选择后可移动端点。绘制同规格的两端箭头与垂直延伸线。文字根据投影边界、其他标注及标题避让，也可手选一侧。 | 标注快照最多 100 步。支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 和工具栏操作。标注位置是二维图纸坐标，局部尺寸文字由用户输入。[标注状态](../src/annotations.ts) · [文字避让](../src/mark-label.ts) |
| 预览与高清导出 | 预览由 3D 底图和 2D 标注叠合。导出从相机、材质和标注重新渲染；逐块留出邻域边距，防止 AO 或辉光在图块边界断开，最后做 Lanczos3 降采样。 | 预览底图以 CSS 宽度 × DPR × 1.25 为目标，宽度上限 3000 px；内部最多 3 倍采样，宽度上限 4200 px。导出 6000 × 4000、300 dpi，2 倍线性超采样，输出图块 896 px，滤波边距 3 px，另加 144 个高分辨率像素用于邻域效果。[预览和分块](../src/sheet.ts) · [降采样与 DPI](../src/export.ts) |
| 保存与设置 | PNG 可用浏览器下载，也可写入用户指定目录；遇同名文件自动编号。网格缓存按源文件和转换脚本内容计算哈希，脚本变化会使用新缓存键。设置页提供缓存位置、统计、清理和默认导出目录。 | 缓存有效期 24 小时。模型渲染和导出在本机完成。Windows 原生目录选择通过本机服务。[设置](../src/settings.ts) · [保存和缓存](../server/local-workbench.mjs) |

## 渲染质量与可调参数

| 选项 | 实现与取舍 |
| --- | --- |
| 棚拍材质 | 以源材质和环境反射为基础，使用 ACES 色调映射和较轻的接触 AO。用来快速看外形和材质。 |
| 高保真棚拍 | 保留源 PBR 或将旧材质转换为物理材质，结合主光、辅光、轮廓光、面光和预滤波环境。用深度与法线计算屏幕空间接触 AO；发光材质单独出一层并模糊合成辉光。适合看接缝、金属高光和屏幕。AO 依赖当前视图中可见的邻域，玻璃为实时近似。 |
| 灰白模线描 | 用法线、深度和材质槽标识分别检测外轮廓、转折、接缝，叠加轻微灰面。可读性取决于模型有没有真实几何边或材质分区。 |
| 曝光 | 滑块 −10 到 +10，默认 0，每格 0.15 EV。曝光系数为基础值 × 2 的「滑块值 × 0.15」次方。预览与导出共享曝光，灰白模和标注颜色独立。 |

高保真模式的基础曝光为 **1.03**，环境反射 **0.58**，接触 AO **0.70**，阴影强度 **0.36**，阴影半径参数 **12**。两块面光强度分别为 **3.0** 和 **1.38**，灯光尺寸及 AO 半径都集中在配置文件。没有粗糙度贴图的识别玻璃使用粗糙度下限，减少过锐反光；纹理按显卡能力启用最多 8 倍各向异性过滤。[灯光参数](../src/render-config.ts) · [材质和玻璃](../src/studio.ts) · [AO、线描与辉光](../src/view-effects.ts)

## 渲染助手

1. 用户配置兼容 Chat Completions 的 URL、模型名及 API Key。Node 本机服务负责转发，浏览器获取设置时只收到密钥是否已保存。请求超时 45 秒，每轮最多 20 项修改。
2. 助手可以编辑共享材质，也可以编辑单个部件的材质槽。前端发送名称、大小、中心、颜色、贴图状态和角色线索。没有源材质时，仍可在四视图上通过相机射线选中实际网格。角色来自名称和几何特征，只用于辅助定位。勾选后，本轮还会发送 1008 × 672 的 JPEG 预览，需服务商的模型支持图像输入。
3. 服务端从标准 JSON、Markdown 代码块或带说明文字的回复里读取建议。前端校验目标范围、类型和参数上下限，再生成待应用列表。用户通过按钮或对话中的「确认」执行。实际渲染状态以工作台应用结果为准。
4. 木材和人造石使用局部三维坐标生成纹理。木纹默认沿部件长轴，可指定 X、Y、Z；密度范围 0.4–2.5，细节 0–1。纹理同时影响颜色、粗糙度和微表面法线，利用屏幕导数抑制远处细纹闪烁。金属、塑料、橡胶、玻璃、屏幕和自发光使用预设作为起点，支持微调及组合通用 PBR 参数。
5. 应用时保留之前的材质和场景参数。按住「对比」显示修改前，松开显示当前效果，换镜头后两个状态都用同一镜头。撤销渲染恢复参数，标注历史和视角独立。当前标注、对话和材质编辑只保留在页面会话内，刷新后需重新导入和编辑。

## 从实际故障沉淀的经验

| 现象 | 定位与修复 | 可复用的做法 |
| --- | --- | --- |
| Rhino 能打开文件，网页缺面或拒绝导入 | 3DM 可只存曲面。转换前检查每个曲面的显示网格；缺网格走 Rhino，转换后再校验。缓存和转换竞争时，旧流程会返回 409；新流程排队并反馈状态。 | 验收同时测首次转换、缓存命中和并发请求。将读文件、生成网格、材质恢复和渲染分开检查。 |
| 正交视图边缘发花，金属局部有白斑 | 识别桌右侧断续高光来自面光在正对相机时的退化计算；白斑来自近乎共面的零件。分别稳定着色计算和局部深度顺序，预览提高采样密度。 | 用原模型、固定镜头和局部裁切做对照。分别排查深度冲突、法线或光照、贴图与光栅采样。 |
| 导出像素很多，边和字仍有锯齿 | 输出直接重绘几何与文字，按最终像素超采样和降采样。 | 检查 PNG 实际像素、斜边、线缆和字形；DPI 元数据只说明打印换算。 |
| 切换视角后无法对比和撤销 | 只保留修改前截图，无法用于新视角。改为保留参数快照，换视角后重新生成对比画面。 | 分开管理观察状态、标注状态和可撤销的材质修改。 |
| 助手找到共用材质，无法只改框架；回复后确认失效 | 给材质槽独立 ID，引入图上点选与部件摘要。兼容说明加 JSON 的回复，应用按钮只在有有效变更时生效。 | 语言模型负责提议；程序负责目标授权、参数校验、显示影响范围、应用和撤销。 |

## 验证与下一轮方向

本次在 Windows Chrome 执行完整 Playwright 回归，12 项通过，覆盖 OBJ、实际 3DM、四视图、标注、PNG、网格转换和缓存、材质修改及撤销。回字形模型另做了并发转换验证，观察到第一份生成缓存、第二份排队后命中缓存。接口测试使用模拟服务。真实视觉模型识别准确率、macOS 实机性能和不同 GPU 的极限尺寸仍待测量。[回归测试](../tests/workbench.spec.ts)

| 优先级 | 建议工作 | 建议验收口径 |
| --- | --- | --- |
| P0 · 导入和出图稳定性 | 建立可分发的合成模型回归库，覆盖缺网格、材质重名、嵌套块、共面、斜边和透明件。增加分阶段错误记录和渲染耗时，实测 macOS Chrome。 | 同一输入连续导入可预测；成功案例无缺件，错误有明确处置指引；6000 × 4000 导出无图块接缝。按设备记录首帧、转换、缓存命中与导出耗时的中位数和 P95。 |
| P1 · 项目保存与恢复 | 设计带版本号的项目文件，保存模型引用、单位、名义尺寸、标注、相机、材质覆盖。提供引用缺失后的重新绑定。 | 保存并重开后可复现同一输出；引用缺失时能定位并替换，保留可编辑标注。 |
| P1 · 助手定位验收 | 收集有名、无名、共用材质和左右对称等指令，分别比较文字自动定位、视觉提示和手动点选。提案里可高亮目标及显示影响数量。 | 建议先用 30 条任务记录目标命中率、误改率、澄清率和确认次数。明确点选单个部件的任务要求其他部件不变。 |
| P2 · 渲染与交付 | 先定色彩、反光和 AO 的参考图，比较不同 GPU 的性能与一致性。若现场确有透明件多次折射或间接光需求，再评估独立离线渲染路径及安装成本。 | 用相同模型和镜头比较实时与离线图，记录耗时、安装前置和可复现性，再决定是否增加后端。 |

网页本机运行步骤和平台限制见 [README](../README.md)。Windows 可调用已授权的 Rhino 8 处理缺网格的 3DM；macOS 和 Docker 可读取 OBJ 与已有显示网格的 3DM。
